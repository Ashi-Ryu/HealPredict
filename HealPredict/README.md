# HealPredict

Adds incoming heal prediction and overheal display to the default WoW unit frames — Extremely Lightweight, no dependencies, no WeakAuras required.

**What it shows**

- **Green bar** — fills the missing HP gap on the health bar, showing how much of an incoming heal will actually land
- **White bar** — extends past the right edge of the health bar when a heal would overshoot max HP, sized to the wasted amount

Covers player, target, focus, pet, and party frames (1–4).

**Compatibility**

WotLK 3.3.5 / Ascension private server.

**Installation**

Drop the `HealPredict` folder into your `Interface/AddOns` directory and reload.
